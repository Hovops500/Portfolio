# Follow these steps to grant access to another subscription in Azure:

<b>Step One:</b> Sign in to the Azure portal.

<b>Step Two:</b> In the Search bar at the top, type Subscriptions and select it.

<b>Step Three:</b> Select the subscription you want to grant access to.

<b>Step Four:</b> Navigate to Access control (IAM) in the left-hand menu.

<b>Step Five:</b> Click Add and select Add role assignment.

<b>Step Six:</b> In the Role tab, choose the appropriate role (e.g., Owner, Contributor, or Reader) based on the level of access required.

<b>Step Seven:</b> Click Next to proceed to the Members tab.

<b>Step Eight:</b> Select User, group, or service principal and click Select members.

<b>Step Nine:</b> Search for and select the user, group, or service principal from the directory.

<b>Step Ten:</b> Click Next to configure optional conditions (if needed, such as restricting role assignments).

<b>Step Eleven:</b> Review the settings on the Review + assign tab and click Review + assign to finalize the role assignment.
