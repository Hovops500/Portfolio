 Creating and Manipulating Arrays

Creating Arrays

NumPy arrays can be created in multiple ways, including from lists, tuples, or using functions like arange and linspace. Here are some examples:

import numpy as np

# Creating a rank 1 array
arr1 = np.array([1, 2, 3])
print("Array with Rank 1:\n", arr1)

# Creating a rank 2 array
arr2 = np.array([[1, 2, 3], [4, 5, 6]])
print("Array with Rank 2:\n", arr2)

# Creating an array from a tuple
arr3 = np.array((1, 3, 2))
print("\nArray created using passed tuple:\n", arr3)

Accessing and Slicing Arrays

NumPy allows for efficient indexing and slicing of arrays. You can access elements using square brackets and perform slicing to get a range of elements:

# Initial Array
arr = np.array([[-1, 2, 0, 4], [4, -0.5, 6, 0], [2.6, 0, 7, 8], [3, -7, 4, 2.0]])
print("Initial Array:\n", arr)

# Slicing the array
sliced_arr = arr[:2, ::2]
print("Array with first 2 rows and alternate columns(0 and 2):\n", sliced_arr)

# Accessing specific indices
index_arr = arr[[1, 1, 0, 3], [3, 2, 1, 0]]
print("\nElements at indices (1, 3), (1, 2), (0, 1), (3, 0):\n", index_arr)

Basic Operations

NumPy supports a wide range of operations on arrays, including basic mathematical operations, unary and binary operations:

# Defining Arrays
a = np.array([[1, 2], [3, 4]])
b = np.array([[4, 3], [2, 1]])

# Adding 1 to every element
print("Adding 1 to every element:\n", a + 1)

# Subtracting 2 from each element
print("\nSubtracting 2 from each element:\n", b - 2)

# Sum of array elements
print("\nSum of all array elements:\n", a.sum())

# Adding two arrays
print("\nArray sum:\n", a + b)
